# Changelog

## 2026-09-21

- Added Flip Glass Light with new clear-glass digits, a pale daylight background,
  soft window shadows, and long reflections that follow the animation.
- Added Flip Glass Light to Home Assistant's Clock Display selector and both
  directions of the swipe cycle, with selection saved across restarts.
- Retained the 1.5-second transition for changed digits and the existing Cars,
  Ants, and dark Flip Glass faces.
- Added transparent sprite compositing, partial redraws, and host coverage for
  all minute boundaries, midnight, background restoration, and display rotation.
- Updated the installation guide and README with the new face and previews
  captured from the firmware renderer.
